b.) Testing Strategies:
Levels of testing (V - Model) :

Requirements -------------> Acceptance Testing

System Design -------> System Testing

Module Design -> Integration Testing

Coding - Unit Testing

1.) Unit Testing: test each function or class (for example,
the cart total calculation). Tools: JUnit,
XCTest, Jest.

2.) Integration Testing: test modules together, especially
app <-> backend <-> payment gateway <-> courier API.
Uses an incremental approach (top down/bottom
up) with stubs & drivers
